# CYGNUSA Technologies Website

Official corporate website for CYGNUSA Technologies — Advise, Build, Run enterprise technology solutions across nine sectors.

## Tech Stack
- **Framework**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide React icons
- **Architecture**: Advise, Build, Run framework

## Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
